Changelog

    

    
A design system is a collection of reusable components and guidelines that helps teams build better products faster. It is the single source of truth for design and code.

    
Components include buttons, inputs, cards, modals, tables — all built on the same token foundation.

    
Design tokens are the core values: colors, spacing, typography, radius, shadows. They live in CSS variables and flow into every component.

    
v2.0 — PRISM engine, inline editing. v1.2 — Dark mode. v1.0 — Initial release.
